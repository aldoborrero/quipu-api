# quipu-client

Multi-language Quipu API client, generated from openapi.json.

## Structure

- nix/ → all nix files (blueprint convention, prefix = "nix/")
- python/ → Python client (first language)
  - quipu_client/ → generated by openapi-python-client from openapi.json
  - quipu/ → thin auth wrapper (OAuth2 client_credentials)
- openapi/ → OpenAPI specs (source of truth)

## Dev workflow

direnv allow # loads flake automatically via .envrc
nix develop .#python # Python-specific shell
nix build .#quipu-python
nix flake check # runs pytest

## Regenerating the client

openapi-python-client generate --path openapi/openapi.json --output-path python/generated --overwrite
rm -rf python/quipu_client && mv python/generated/quipu_client python/

## Credentials

QUIPU_APP_ID and QUIPU_APP_SECRET — set in .envrc.local (gitignored)

## Adding a new language

1. Add nix/devshells/{lang}.nix
1. Add nix/packages/quipu-{lang}/default.nix
1. Generate client from openapi/openapi.json into {lang}/
